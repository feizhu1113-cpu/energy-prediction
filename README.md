# 新能源汽车遥测数据挖掘与能耗预测

## 项目背景
基于168万行真实新能源汽车遥测数据，深入分析「人-车-环境」多维互动对电池续航的影响，挖掘核心衰减因子，并提出产品化建议。

## 数据规模
- **168万行**真实遥测数据
- 核心字段：车速、踏板开度、电池温度、环境温度、SOC、SOH等
- 时间跨度：覆盖四季（重点分析冬季低温场景）

## 核心发现

| 发现 | 量化结果 |
| :--- | :--- |
| 踏板开度重要性 | **0.702**（约为车速 **0.210** 的 **3.5倍**） |
| 冬季低温影响权重 | **0.833**（主要矛盾） |
| 用户充电行为 | 普遍「浅充浅放」，影响电池健康 |

## 产品化建议

1. **智能温控预热提示**：冬季低温时主动提醒用户预热电池，提升续航
2. **千人千面续航预测**：基于用户驾驶习惯（踏板开度、车速），动态预估剩余续航
3. **充电行为引导**：针对「浅充浅放」用户推送充电优化建议
